# E-Commerce Website UI/UX Design (Figma)

## 📌 Project Overview
This project presents a complete UI/UX design of a modern e-commerce website created using **Figma**.  
The design focuses on intuitive navigation, clean visual hierarchy, and a smooth end-to-end shopping experience.

## 🎯 Project Objectives
- Design a user-friendly e-commerce interface
- Ensure a smooth user journey from browsing to order confirmation
- Apply standard UI/UX principles used in real-world e-commerce platforms

## 🖥️ Screens Designed
- Home Page
- Categories Page
- Product Listing Page
- Product Details Page
- Festive Sale Page
- Cart Page
- Checkout Page
- Payment Page
- Order Confirmation Page
- User Profile Page
- Login / Signup Page

## 🛠️ Tools & Technologies
- Figma (UI/UX Design)

## 🧠 UX Highlights
- Clear product categorization and filters
- Consistent color palette and typography
- Prominent call-to-action buttons
- Minimal and clutter-free layout
- Optimized checkout flow
